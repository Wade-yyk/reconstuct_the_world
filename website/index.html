IMPLEMENTATION IN P1.PY

Implementation descriptions

Linear eight-point

lls_eight_point_alg

1(b) · Description of the linear eight-point implementation

To estimate F, suppose the same point is represented by x₁ = (x, y, 1) in image 1 and x₂ = (u, v, 1) in image 2. We want Fx₁ to give a line in image 2 on which x₂ lies, so that x₂ᵀ F x₁ = 0. The corresponding row of the design matrix is [ux, uy, u, vx, vy, v, x, y, 1].

In Set 1, we use 37 such point pairs, and in Set 2, we use 46. We stack at least eight rows and use the last right singular vector to fit the nine coefficients of F up to scale. A second SVD sets the smallest singular value of F to zero, enforcing rank two. Geometrically, the lines in each image share an epipole.

1(b) · Resulting fundamental matrices

Point-to-line distance

compute_distance_to_epipolar_lines

1(f) · Description of the point-to-epipolar-line distance calculation

First, we use the points in image 2 to calculate the corresponding epipolar lines in image 1.

lines = points2 @ F

We substitute each point in image 1 into the equation of its corresponding line and take the absolute value. We divide by the length of the line’s normal vector to obtain the perpendicular distance.

d = |ax + by + c| / √(a² + b²)

We then average these distances across all matched points. To calculate the mean distance for image 2, we swap the two sets of points and use Fᵀ in place of F.

1(c) · Normalized eight-point implementation

Compared with 1(a), the normalized eight-point algorithm first computes the centroid of the matched points in each image and chooses a scale factor so that their average distance from the centroid after scaling is √2. We apply the translation and scaling to both sets of points using points @ transform.T, then use the eight-point algorithm from 1(a) to estimate F_normalized. Finally, we transform the matrix back to the original pixel coordinates and scale it to unit norm.

F = transform2.T @ F_normalized @ transform1
return F / np.linalg.norm(F)

QUESTION 3 · STRUCTURE FROM MOTION

The factorization method

3(a)–(b) · Implementation

factorization_method

First, we put each pair of matched points in the same column. For example, if the first point is (100, 200) in image 1 and (150, 250) in image 2, the first column is [100, 200, 150, 250]ᵀ. Set 01 contains 37 matching pairs, so the matrix has dimensions 4 × 37.

Next, we subtract the mean of each row from every entry in that row to form the centered measurement matrix W. This removes the translation term in each image’s affine projection.

p = AX + t   ⇒   p − p̄ = A(X − X̄)

We then apply SVD to W and keep the three largest singular values to recover 3D coordinates.

W ≈ U3Σ3V3ᵀ

We split Σ3 into two square-root factors to obtain the camera motion matrix M and the 3D structure matrix S, whose product approximates W.

M = U3√Σ3   (4 × 3)
S = √Σ3V3ᵀ   (3 × N)

4(b) · Linear triangulation

linear_estimate_3d_point

Let Pi be the camera matrix for image i, Xh = [X, Y, Z, w]ᵀ the homogeneous 3D point, and (ui, vi) the observed pixel. The perspective projection satisfies the following equations.

ui= Pi,1Xh Pi,3Xh vi= Pi,2Xh Pi,3Xh

Each image contributes two linear equations from its camera matrix and measured pixel coordinates. Stack the equations, use the last right singular vector as the homogeneous point, and divide by its fourth coordinate to get the 3D position.

Triangulated 3D points for views B21 and B22

4(c) · Reprojection error and Jacobian

reprojection_error · jacobian

We project the 3D point into each image. If the homogeneous projection is [a, b, c], the predicted pixel is (a/c, b/c). We subtract the measured pixel coordinates from the predicted coordinates. For two images, this gives four error values.

e = [Δu₁, Δv₁, Δu₂, Δv₂]ᵀ

Next, we calculate how the error changes when the 3D point moves in each of the three spatial dimensions. We differentiate the projected x and y coordinates with respect to X, Y, and Z using the quotient rule. For K views, the Jacobian has 2K rows and three columns. The vector e gives the current deviation, and J describes how moving the 3D point changes that deviation.

Reprojection errors and Jacobians for views B21 and B22

The residuals are in pixels. Each row of J corresponds to the same entry in e.

4(d) · Nonlinear refinement

nonlinear_estimate_3d_point

We initialize the 3D point with the linear estimate and apply ten Gauss–Newton updates to minimize the squared reprojection error. In each iteration, we recompute the residual e and the Jacobian J at the current point. If the point moves by Δ, we approximate the new residual as follows.

e(X + Δ) ≈ e(X) + JΔ

We choose Δ to minimize the squared norm of this linear approximation, then update the point to X + Δ.
